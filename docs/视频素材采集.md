# 视频素材采集与候选稿审核

后台入口：`/admin/imports`。支持 YouTube 单视频、哔哩哔哩 BV/AV（含分 P 和 b23 短链接）、公网 HTTPS MP4 直链。

## 使用顺序

1. 在「AI 草稿配置」配置可用的 MiniMax 文本 API，保存并启用。
2. 打开「素材采集」，输入视频链接，选择文章模板与整理方式。
3. 优先读取平台可获取的字幕。也可以粘贴字幕或导入 SRT、VTT、TXT、字幕 JSON；提供字幕后不再访问视频。
4. 如果没有字幕，可单独勾选「允许视频语音转写」。目前仅对 MiniMax 官方接口启用，使用同一服务端 Key 调用 `asr-1.0`；语音转写权限、额度可能与文本模型不同。
5. 完成后点击「查看并审核候选稿」。核对来源、事实、命令和画面，采用候选稿，再保存草稿。正式发布必须勾选确认发布并再次确认。

短素材默认简洁整理，避免机械填满教程章节；也可以选择完整教程。不会把别人的测试经历写成自己的亲测经历。

## 边界与失败处理

- 总结依据是字幕或语音，不包括自动理解画面、代码截图、演示动作。画面信息需要人工补充。
- 平台可能限制公开字幕、要求登录或因网络不可达而失败。不会绕过登录或付费限制，也不会仅凭标题生成总结。任务会提示补充字幕或手动重试。
- 每段最多 10 分钟，媒体下载最多 80 MB，转写音频最多 8 MB，字幕最多 40000 字符。平台字幕优先中文、英文，最多尝试三种语言。
- 语音转写默认关闭。提交任务可能产生文本 API 费用；启用语音转写后还可能产生转写费用。取消不能撤销服务商已受理的计费请求。
- 最多排队 10 项，每小时最多提交/重试 10 次；文本生成共享每小时 10 次上限。相同输入的待执行或已成功任务复用原任务。失败任务手动重试，最多三次。
- 运行中断后，租约过期的任务转为需要处理，管理员查看任务列表时恢复检测；不自动重试已发出的付费调用。排队任务在管理员访问任务列表时继续运行。

## 数据与未来 Agent

任务队列保存在原 SQLite 数据库新增的 `video_import_jobs` 表，保留来源、状态、尝试次数和失败原因。字幕、候选稿和参考来源存储在文章的后台私有素材字段。成功任务创建未发布文章，正式正文为空，需人工采用候选稿。

未来定时 Agent 可复用入队函数和同一候选稿流程；本轮未启动定时采集、未提供公开 Agent 密钥，也没有自动发布入口。已有管理员文章 API 仍支持管理员明确发布，采集 worker 不调用该发布能力。

私网地址、IP 直链、不安全协议被拒绝；下载逐跳校验 DNS 并固定公网解析，限制大小、超时和临时文件。带签名的 MP4 参数仅留在后台任务，不自动写进公开参考来源。部署需整体备份数据目录以包含新队列表和素材。

## 部署与验证

Docker 运行层新增 Python、固定版本 yt-dlp 和 FFmpeg；必须重建镜像，旧镜像不能只覆盖源码。NAS 构建与真实平台网络需分别验收。

本轮验证：单元测试覆盖字幕解析、私网/重定向拦截、大小限制、队列去重/取消/事务回滚；实际运行本机 FFprobe/FFmpeg 提取测试视频音频。字幕服务、文本模型和 ASR 服务测试使用模拟响应，不代表真实平台字幕或正式账户额度已验证。未调用正式付费 API。

## 本地视频

来源方式切换至「选择本地文件」可选 MP4、WebM，提交时流式上传，限制 80 MB；后端验证文件签名，转写前 FFprobe 检查实际时长（10 分钟）。文件名不参与磁盘路径，源文件以随机 ID 存于数据库目录旁的 `video-imports` 私有目录，未提供公开下载路由，也不自动绑定文章附件。

没有补充字幕时，本地视频需要单独启用语音转写。支持取消上传；失败清理不完整文件，上传成功而入队失败可重用已上传文件。原视频总预留容量 800 MB，超过七天的非处理中源文件在下一次上传时清理；管理员也可在终态任务卡片删除源视频，已生成候选稿保留。重试前请确认源视频仍存在，删除后需重新选择文件。部署、备份应包含该目录。

## 长视频字幕

自动获取平台字幕不受 10 分钟限制（字幕仍受 40000 字符上限约束）；只有下载音视频进行语音转写才限制 10 分钟。页面默认隐藏手动字幕输入，输入视频链接即可提交。

2026-10-19 对用户提供的 YouTube 视频进行只读字幕探测：平台元数据返回 1130 秒及五条中文字幕轨道，但当前本机字幕域名解析为非公网地址，被下载安全检查拒绝。因此该视频的自动字幕成功尚未验证；不得为了适配代理 DNS 而直接取消私网拦截。此探测未生成文章、未调用付费 AI。
