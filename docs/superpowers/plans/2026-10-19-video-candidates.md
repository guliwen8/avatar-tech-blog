# 视频素材采集与候选审核实施计划

目标：YouTube、哔哩哔哩、MP4 链接进入持久化任务队列；字幕优先，用户单独允许时转写；AI 整理结果只产生候选草稿，由管理员采用后主动确认发布。后续 Agent 复用同一入队与候选保存函数，本版不建立自动发布或定时采集。

1. 编辑策略：editorial 增加 auto/concise/complete，短素材自动简洁输出，缺失无关章节不列为问题；新文章默认草稿，发布前正文非空并人工确认。纯函数测试和编辑器浏览器测试。
2. 任务状态：SQLite video_import_jobs；queued/running/succeeded/needs_input/failed/cancelled；单并发、租约和取消、中断后等待人工重试；同链接活跃/成功任务去重；候选写入和任务完成同事务，始终 published=false、content为空、candidate单独保存。单元测试使用模拟采集和模型。
3. 来源适配：URL 限制平台视频或公网 HTTPS MP4，链接和字幕下载逐跳公网 DNS/IP 校验及固定地址；yt-dlp 仅读取平台公开字幕，失败不登录绕过，允许转写时下载有上限的音频；MP4 限长与限体积、本地 ffmpeg 提取音频；MiniMax ASR 仅官方域名且单独启用。不凭标题生成内容，保留来源且说明仅基于字幕/语音。
4. 任务运行：Next after 在响应后运行，SQLite 保存状态；管理员轮询唤醒排队任务；每个任务最长10分钟，输出原稿最多40000字符，超长须分段；不自动重试付费阶段。部署镜像包含固定版本 yt-dlp 与 ffmpeg。
5. 管理界面：素材采集输入链接、可补充字幕、模板和整理方式；状态、原因、重试、取消、查看候选稿；文章工作台可跳转此入口。
6. 验证：真实本地 ffmpeg 处理样本，平台公开字幕可达性检查；单元测试模拟网络/ASR/LLM 验证安全和状态；浏览器使用独立数据库验证草稿与发布确认。未调用付费服务时不得声称已验证真实总结质量；NAS 部署须备份数据库与整个文件目录。

限制：部分平台链接会受登录、地区或网络限制；不保证任意链接可采集。无法读取时允许用户补字幕。内容总结不等于看过画面，命令、屏幕内容需另行核验。
