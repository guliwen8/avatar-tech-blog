# 管理员认证

- 沿用 users、sessions 表和已有管理员账号，不重置 NAS 密码、不迁移会话格式。
- 会话最长七天，服务器根据 sessions.created_at 校验。SQLite 默认时间按 UTC 解析。过期、异常时间、未来时间均拒绝；角色必须为 admin 且账号仍存在。
- 修改密码作用于当前登录管理员；新密码至少 10 个字符、最多 72 字节。更新密码和删除该管理员全部会话在同一事务中执行。前端清除当前 Cookie 并跳转一次到登录页，其他设备的旧会话也立即失效。
- 管理员登录沿用数据库持久化限速：每个规范化用户名 15 分钟最多 10 次尝试；全站 100 次。达到上限返回 429、Retry-After: 900。成功与失败均计数；不信任客户端提供的 IP 来绕过限速。账号键使用 SHA-256，不保存输入密码。
- 登录、退出以及后台设置/广告/套餐/模块/文章的写入均校验 Origin。会员、咨询、私有文件原有同源校验保留。无 Origin 的命令行写请求需要显式提供与目标站点一致的 Origin。
- 会话 Cookie 为 HttpOnly、SameSite=Lax；HTTPS 请求或受信反向代理传入 X-Forwarded-Proto: https 时附加 Secure。本地 HTTP 预览可正常登录。
- /api/auth 状态响应 private/no-store。401 不主动重定向；后台未确认登录前不挂载数据页面，避免刷新循环。

## 发布时核验

1. 备份数据库和私有文件目录。已有七天以上的管理员会话会失效，需要重新登录；管理员密码不变。
2. NAS HTTPS 反代应覆盖 X-Forwarded-Proto，并保留正确 Host。通过真实域名核验登录响应的 Secure Cookie 和 Origin 校验；本地模拟不能替代这一项。
3. 确认线上管理员已更换初始密码。本次未访问或更改 NAS 密码；现有空库初始化机制仍需在首次部署时更换初始密码。公开登录页不再展示初始凭据。
4. 如其他脚本调用后台写 API，补充正确 Origin；读取接口不要求此头。
