# 网页与 RSS 素材采集（首版）

入口：后台「素材采集」→「网页与 RSS」。默认入口仍为粘贴文字，视频功能保留为可选，不继续扩展。

## 使用

- 单篇网页：选择「单篇网页文章」，输入公网 HTTPS 文章地址，点击「仅采集正文」或「采集并生成候选稿」。
- RSS / Atom：选择订阅类型，输入订阅地址，读取列表，最多显示前 20 个有效条目，每次手动选择最多 3 篇文章。读取列表不调用 AI，真正采集时再读取所选文章的正文，不把订阅摘要当作全文。
- 「仅采集正文」把提取的 Markdown 与出处保存到后台私有素材字段。正式正文为空，发布状态为草稿。
- 「采集并生成候选稿」在保存素材后调用现有 AI 整理器，生成结果仍放在候选字段。AI 未配置、失败或中断时保留素材草稿，可以在文章编辑页继续整理。已经保存的草稿不会因停止后续采集而删除。
- 点击结果中的草稿链接，核对提取内容、出处与候选稿，再采用、保存并主动确认发布。

## 保留与限制

保留文章标题、原作者元信息（网站提供时）、最终来源地址，以及正文中的标题、列表、代码与基础表格；不自动下载图片、执行网页脚本或加载网页资源。正文提取是启发式判断，广告、付费提示或动态加载可能影响结果，仍需人工核对。复杂表格、公式、图片和演示信息不保证完整还原。

仅支持公网 HTTPS；每次请求限 2 MB，正文限 40000 字符，不静默截断超长素材。原文编码按 UTF-8 处理；非 UTF-8 或复杂动态站点可改用手动粘贴。需要登录或付费的页面不绕过限制。

RSS 首版支持 RSS 2.0 与 Atom，不抓取整个网站，不设置定时任务，不给外部 Agent 发放密钥。管理员接口按会话和同源校验授权，每小时最多读取订阅 10 次、采集文章 10 次；AI 生成与已有入口共享每小时 10 次额度。

## 去重与并发

新增 `web_import_sources` 来源索引，关联原地址、重定向后地址与文章 slug。去除锚点和常见追踪参数后的相同来源复用已有文章；不做全文语义去重，也不保证不同查询参数或不同镜像链接识别为同一篇。

重复采集不重新调用 AI，也不覆盖已编辑或发布文章。需要重新整理时，到已有文章编辑页主动生成候选稿。候选稿写入前再次检查文章仍为未发布、正文为空、原始素材未变化且不存在其他候选稿，避免异步生成覆盖人工编辑。

网络失败显示原因；域名解析为非公网时保留安全拦截。本文档不把所有网站宣称为已适配。发布前应核对来源、引用、事实与技术参数，原文重复提醒不等于全网查重。

## 本轮验证

单元测试覆盖 HTML 正文、代码与表格提取，RSS / Atom、实体解码、订阅去重、私网与非 HTTPS 过滤、拒绝 DTD/实体声明、超长正文、草稿持久化、重复来源、事务回滚以及不覆盖已编辑正文。

真实网络测试读取 Mozilla 官方 RSS（20 条），实际提取一篇约 3869 字符文章并保存为未发布素材草稿，重复请求复用同一文章，匿名访问返回 404。没有调用付费 AI。另实测 Node.js 长篇发布说明超出正文上限时明确拒绝，未截断。

浏览器测试验证管理员/同源/私网检查、RSS 勾选上限和桌面/手机布局；部分 UI 成功响应使用模拟数据。正式 MiniMax 的完整生成质量仍由正式账户验收。本轮不部署 NAS。

依赖与运行：新增解析依赖固定版本，DOM 解析不启用脚本与远程资源。jsdom 需要 Node.js 22.13 以上（或对应支持版本），NAS 更新需重建镜像并先做候选镜像自检。依赖扫描未在新增解析依赖中报告告警，但仓库已有 Next/PostCSS、gray-matter 等共 6 项告警（1 高、5 中），已记录在 QA 报告，未在本轮做跨大版本强制升级。

## 零度博客来源验收（2026-10-20）

用户指定 `https://www.freedidi.com/`。订阅模式支持输入网站首页：优先识别同源 RSS/Atom 链接，根路径未发现链接时只尝试一次同源 `/feed/`，不执行网页脚本。

零度文章页对本机直接请求返回 JavaScript 跳转页，不执行该脚本。其公开 RSS 提供 `content:encoded` 正文字段，因此从 RSS 选择文章时优先提取该字段，记录订阅地址和“RSS 全文提取”；没有正文字段才请求文章页。绝不把 description/summary 当作全文。订阅正文字段由站点提供，不保证与网页展示完全一致，图片和视频仍不下载。

实测首页发现零度 RSS，返回 9 个条目；其中两篇分别提取约 1805、2804 字符，后一篇保留了 2 个代码块。未调用付费 AI，未发布文章。订阅列表只返回“有正文字段”标识，不向列表界面传输整篇 HTML；采集时服务端重新读取所选来源并核对条目链接。
