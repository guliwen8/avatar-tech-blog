# 本站私有文件与咨询截图

## 上传与使用

- 后台文章编辑器选择「视频」后可上传 MP4/WebM，单文件最大 100 MB；选择「免费资源」可上传 PDF/ZIP/7z，最大 50 MB。
- 上传会填写本站 `/api/files/<编号>` 地址；请等待上传结束后保存文章，上传期间保存按钮禁用。文件在绑定并发布文章前仅管理员可访问。
- 同一文件只绑定一篇文章，不能直接把它的本站地址复制到另一篇文章使用；请重新上传副本。这样一篇文章改权限不会意外影响另一篇文章。
- 本站文件跟随文章的公开、登录、有效会员权限。取消发布、移除文件链接、会员到期或退出后，新的文件与分段请求会重新核验权限。已经获得的文件或缓冲数据无法远程收回，不提供 DRM。
- 外部 HTTPS 视频/下载仍由来源站控制。真正受限的本站视频不能使用公开 `/uploads/` 文件。

## 咨询截图

先提交咨询，再在详情里添加 PNG/JPEG/WebP；单张最大 5 MB，每条咨询最多 9 张，同一账号截图总量最多 100 MB。只允许咨询本人和管理员查看。

用户只能删除自己上传的截图；关闭的咨询不再允许用户增删。管理员可在文件管理中处理保留或删除需求。回复中的截图绑定整条咨询，不绑定某一条文字消息，界面会区分站长与用户上传。

文件只按扩展名和文件头识别支持的格式，不代表完成了病毒扫描或内容审核。请先遮住截图里的密码、密钥和无关个人信息。

## 存储与备份

文件存储在 `FILE_STORAGE_PATH`；未设置时，使用数据库同目录下的 `private-files/`。NAS 数据库位于 `/app/data/blog.db` 时即 `/app/data/private-files/`，沿用现有 `/app/data` 持久化挂载。文件不写入 `public`，不进入 Git 或应用构建包。

默认文件总配额 2048 MB，可通过 `FILE_STORAGE_LIMIT_MB` 调整（最低 100 MB）。上传按流写入临时文件，实际字节数、类型校验通过后才成为可读取文件；正常中断或失败会清理预留记录及临时文件。进程崩溃留下的未完成记录由管理员在文件管理中检查后清理。

新增 `private_files` 元数据表，不重建原表。部署前除 SQLite 备份外，必须一并备份对应的 `private-files/`，仅备份数据库不能恢复文件。更新代码时保留整个持久化数据目录。

目前只做本地验证，NAS 代理的实际上传大小、超时、HTTPS 及分段响应还需部署时核对。
