# 素材整理与 AI 草稿

## 编辑流程

文章编辑器中增加素材整理工作台。原始素材、来源、候选稿与正式正文分别保存；素材随文章保存，不会自动保存。支持技术教程、工具介绍、资源分享、随笔四种模板。

1. 填入或从当前正文导入素材，选择模板，记录参考来源。
2. 可插入空白模板结构自行编辑；此操作是排版辅助，不是 AI 改写。
3. 配置 AI 后，点击“AI 整理成草稿”才发送素材与来源；保存配置、修改文字和预览不会调用模型。生成可能产生服务商 API 费用。
4. 对照原文修改候选稿。右侧标题、摘要、正文可编辑；下方沙箱预览使用与正式文章相同的 Markdown 渲染和样式。预览不执行脚本，正文原始 HTML 不启用。
5. 核对事实、命令、链接与来源并勾选确认，才能采用候选稿。已有正文被替换前会再次确认；采用后取消立即发布，先保存草稿，可撤销本次采用。
6. 保存文章后可重新打开继续整理。原始素材只用于后台编辑，不参与公开搜索，不进入文章页、公开列表或 RSC 数据。

素材保存上限 40000 字符；候选正文上限 50000 字符。自动检查覆盖代码块、内联代码、URL 和版本号的遗漏/改动，不能证明事实或含义完全一致；仍需人工审核。AI 不得编造亲测、经历、参数与引用，未确认信息必须提示。不能保证“每句话都不同”或替代来源标注。

## AI 配置

后台菜单“AI 草稿配置”：支持 OpenAI 兼容 Chat Completions，填写服务商提供的 Base URL（如包含 /v1 的地址）、模型名和 Key，再启用。协议参考：[Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。不支持直接填写 Anthropic/Gemini 原生接口；需兼容网关。

- 只连接公网 HTTPS（443），逐次解析并固定已校验的公网 IP，不跟随重定向，不自行抓取来源网页。
- Key 存在 SQLite 专用 editorial_ai_config 表；配置读取只返回 hasKey，不返回原 Key，公开 settings 接口不包含它。数据库备份包含 Key，需保密；这不是加密密钥库。
- 更换 API 地址必须重新提供对应 Key，避免旧 Key 被误发到新服务。
- 输出上限 4096 tokens，单次网络请求最长 90 秒，响应不超过 2 MiB，每小时最多 10 次生成。超长材料建议分节整理；截断输出直接报错，保留已有候选稿。
- 服务商必须支持 max_completion_tokens、store:false 与 messages；实际兼容性和费用以所配置服务为准。模型输出需要有效 JSON，错误不覆盖素材或正式正文。
- 所有配置、预览、生成接口都要求管理员及同源校验，响应 private/no-store。

## 持久化与后续 Agent

posts 新增 editorial TEXT NOT NULL DEFAULT '{}' 列，迁移可重复；旧正文、权限和阅读量不变。字段包含 source、sources、template、candidate、warnings，属于后台私有数据。

生成入口为 POST /api/admin/editorial，action=generate；参数 source、sources、template，返回 title、description、content、warnings。不在该入口发布或保存文章。后续 Agent 应复用整理规则与渲染器，并使用独立授权机制；本版没有给外部 Agent 发放凭据或开放匿名生成。

## 验证边界

自动化测试使用独立数据库和模拟 AI 返回，验证编辑流程、传输协议、权限、素材隔离与错误保护，不调用付费模型。真实服务商密钥与模型尚待用户在后台配置后实测；不把模拟响应当作真实 AI 效果验收。

## 默认素材采集入口

`/admin/imports` 默认打开「文字与文档素材」：粘贴杂乱文档或笔记，复用素材整理工作台生成并预览候选稿，核对采用后点击「保存草稿并继续编辑」，进入文章编辑页设置分类和确认发布。原始素材、候选稿与采用后的正文分别保留。没有采用候选稿时也可保存素材草稿，正式正文仍为空。

视频功能保留在「视频素材（可选）」中，暂不继续扩展平台采集能力。页面内切换两种素材类型会保留已输入文字，刷新或离开页面前仍需保存。

## 内容自审与重复提醒

生成规则要求先提炼事实、独立编排结构和说明，输出前检查整段照抄、广告口吻、他人经历与虚构亲测。命令、代码、链接、参数、版本等技术字段仍须保持准确；必要原文引用需明确标注来源。

系统另对去除代码、行内技术字段和链接后的说明文字做连续长段重复检测，发现与原始素材连续重复时提示重写。此检测仅比较本次输入素材，不是全网查重，也不证明原创或事实正确。生成结果仍由编辑核对、采用和发布，已有已发布文章不自动改写。

## 2026-10-20：长生成等待修复

原来请求固定在 90 秒主动中断；提高 MiniMax 输出额度后，长生成仍可能超过此时限。现在模型请求最多等待 5 分钟，手动工作台生成使用 NDJSON 持续连接，每 10 秒发送等待状态，设置 no-store/no-transform 与 X-Accel-Buffering:no。只在完整 JSON 草稿校验成功后返回候选结果，不展示或采用残缺正文。

取消或断线不会自动重试；原稿与旧候选保持不变。取消不能保证服务商已接收的任务不计费。反向代理若设置固定总时长限制，仍需单独核对；心跳只用于避免无响应的空闲超时，不保证绕过所有网关限制。网页/RSS 入口可先仅采集正文，再到素材工作台整理。

验证使用模拟响应和模拟时钟，没有调用付费服务。实际账户延迟和额度仍需上线后手动确认。
