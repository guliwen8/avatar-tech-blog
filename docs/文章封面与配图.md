# 文章封面与配图

本地实现：MiniMax `image-01`，16:9，一次一张。视频 H3 不属于本次改动。

## 使用

1. 后台「AI 草稿配置」下方有独立的图片配置。选择与账户匹配的官方地址，填写独立密钥；或明确勾选共用文字密钥（地址必须一致）。默认关闭。
2. 在文章编辑器或文字素材采集页，先准备候选标题、摘要和正文。
3. 「文章封面与配图」根据标题、摘要和最多三个章节准备图片描述，可修改。此步骤不调用模型。
4. 点击生成一张图片，确认后调用 MiniMax。图片保存到文件管理，候选列表随文章保存。失败不自动重试。
5. 封面预览后点「采用为封面」，写入封面栏并设为草稿；正文图点「插入候选稿」，再审核并采用候选稿。插图有 AI 生成示意图说明。
6. 保存草稿，核对后手动发布。可移出候选或修改描述重新生成，也可使用原有封面地址替换。移出候选不删除文件、不更改已采用的正文。

## 费用和存储

- 年度会员是否覆盖 API 调用，由具体账户、密钥类型和套餐权限决定；不假定免费。
- 不自动启用，不自动调用，不自动发布；每小时最多 20 次图片生成，每篇最多 12 张候选。
- 官方接口 `/v1/image_generation`，模型 `image-01`，`n=1`。不接受自定义第三方服务地址。
- 下载结果到现有私有文件存储，不把 24 小时临时 URL 写进文章。限制 12 MB，校验 PNG/JPEG/WebP 文件头。
- 带密钥请求不重定向；下载不带密钥，校验公网 HTTPS 和固定 DNS，不执行返回内容。
- 停止等待不能保证撤销服务商已经接收的生成，仍可能计费；已落盘但没加入候选的图片可从文件管理找回。
- 未绑定、未发布图片仅管理员可见。已发布封面随文章列表公开；正文图跟随公开/登录/会员权限。正文敏感图不要同时作为公开封面。
- 未引用的文件保留在文件管理，由管理员清理；正在被文章引用的文件不能删除。
- 本次仅新增独立配置表，不更改现有文字配置，不需要重建文章表。

## 验证边界

接口与浏览器验证使用模拟服务商结果，不调用付费模型。实际账户的图像 API 权限、计费和生成质量需配置后生成一张确认。
