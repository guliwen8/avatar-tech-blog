# 内容发现

- 栏目右侧模块只显示全站文章搜索框；输入后回车或点击放大镜，提交至 /search?q=关键词，搜索范围不受当前栏目限制。搜索权限规则不变。分类入口保留在独立的内容索引模块。分页保留在网址并支持刷新、前进后退。
- 每页 12 篇。异常页码回落到第一页，超过实际页数时显示最后一页。
- 全站正文搜索入口为 /search，输入后点击“搜索全文”或回车。匹配不区分大小写，当前为连续字符串匹配，不做分词或相关度排序。
- 标题、摘要、分类、标签属于公开预览字段，所有人可搜索。原始 Markdown 正文仅在当前账号具有阅读权限时参与匹配；匿名用户不能通过登录可读或会员专属正文命中，过期会员也不能通过会员正文命中。
- 搜索仅返回已发布文章的公开元数据，不向浏览器传输原始正文、私有下载地址或正文片段。结果按现有发布日期排序。搜索结果页使用动态渲染及 private/no-store 响应。
- 标签索引 /tags；标签页只匹配完整标签。归档 /archives 按月份列出已发布文章。索引不包含草稿。
- 当前小规模内容使用服务器扫描，不新增 SQLite FTS 表或迁移。内容量显著增长后再考虑全文索引。
