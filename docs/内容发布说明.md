# 视频、资源与项目的发布方式

旧文章继续兼容现有分类与标签；新内容推荐使用后台专用类型和资料字段。本轮新增的 details 列及迁移说明见下文。

- 教程：分类或标签使用「教程」。
- 视频：分类或标签使用「视频」或「视频教程」。正文中插入 HTTPS 的 `.mp4` / `.webm` 文件链接，会在详情页显示原生播放器。播放能力取决于来源服务器、文件编码和浏览器支持；其他平台视频使用普通链接打开，不自动嵌入第三方网页。
- 免费资源：分类或标签使用「免费资源」或「资源」，不要开启 VIP 标记。正文写明适用系统、版本、来源、使用方法和原始下载地址。
- 开源项目：分类或标签使用「开源项目」或「开源」。正文写明项目介绍、代码仓库、许可证、运行环境、安装步骤和演示入口。

正文里的 HTTPS 外部链接会自动整理成资料卡；卡片只表示原文提供了链接，不代表本站校验过软件安全或提供了文件托管。

文章中的二至四级标题自动生成目录；代码块支持复制。封面支持站内 `/uploads/` 图片和 HTTPS 外链；后台地址、HTTP 和裸 IP 地址不会作为封面显示。HTTPS 外链也可能失效，加载失败时会显示分类占位。

NAS 已有文章的封面误填成后台地址，仍需在管理后台更换成实际图片；前台过滤不会改写数据库里的原始内容。请勿上传数据库或把后台地址当作图片地址。

VIP 角标与正文权限分开设置。旧文章默认公开；新文章可选择公开、登录后可读、有效会员可读。真实在线支付尚未接入。

## 专用资料字段（本轮新增）

后台文章编辑器增加「内容类型与资料」。新内容可明确选择普通文章、视频、免费资源或开源项目；旧数据默认自动识别，不会批量改分类。

- 视频发布时至少填播放地址或原平台链接；草稿允许暂不填写。平台观看页只能用原平台链接打开，不会被当作视频文件。
- 免费资源发布时需要下载地址；可附版本、适用平台和来源。
- 开源项目发布时需要仓库地址；可附演示、版本、许可证和运行环境。
- URL 只接受 HTTPS；视频另支持已存在的 `/uploads/` MP4/WebM。旧 /uploads/ 路径必须由部署者放置实际文件且仅用于公开内容。新增的后台私有上传请见《私有文件说明》，受限内容优先使用上传生成的 /api/files/ 地址。
- 这些资料会显示在列表卡片和详情页顶部，正文继续使用 Markdown。
- 未填写的可选字段不显示，也不会自动编造版本、许可证或项目统计。

数据库新增 `posts.details` JSON 文本列，默认 `{}`。迁移可重复执行，不重建表、不重写正文、订单或阅读数。部署前仍应备份 NAS 数据库；本轮测试仅使用副本。旧版应用不会使用新列，回退应用代码时不要删列。

公众账号、正文权限和咨询受理已加入后续阶段；文件上传另见《私有文件说明》；真实在线支付与自动发布 Agent 尚未接入。

## 账号、正文权限与咨询

- 公众账号在 `/register` 注册，`/login` 登录，`/account` 查看会员状态、修改密码或退出。与后台管理员独立。
- 后台「读者与会员」可设置到期日期（UTC）；请先完成实际开通确认。到期或撤销会员后，下次请求立即按普通读者处理。
- 文章编辑器「正文访问权限」独立于 VIP 角标。旧文章保留公开状态，不批量把角标改成付费门槛。受限正文、解析后的链接、专用视频/下载地址会在服务端过滤；公开标题、摘要、封面和标签仍用于内容发现。
- 权限保护的是本站正文与链接展示。公开 uploads 文件和第三方媒体源不会因此变成私有文件；本站新上传的文件已经按文章权限鉴权，外部地址仍需来源站控制。不要把密钥写进链接。
- 咨询在 `/consult` 登录后提交，用户只能看自己的记录。后台「咨询管理」可回复、关闭与重开。当前不收取积分、不自动发邮件或承诺回复时限；新增咨询截图的限制见《私有文件说明》。旧浏览器草稿可由用户主动导入。
- 找回账号采用人工核验；后台重置密码会撤销该账号所有会话。当前不提供邮件重置和邮箱验证。
- 公开模拟支付入口已关闭，不会根据模拟订单授予会员。旧订单记录保留在后台。
- 数据库仅新增 members、member_sessions、member_limits、consultations、consultation_messages 及索引，不改动旧管理员或会话表。会话令牌只存哈希，有效期七天；旧记录按需清理。

本地检查不等于已经部署：NAS 需要备份后另行更新。
